# Car Price Prediction using Machine Learning

## Project Overview

Car price prediction is a common regression problem in machine learning. The selling price of a car depends on several factors such as brand reputation, mileage, fuel type, and transmission.

This project develops a machine learning model that predicts the selling price of a car based on its attributes.

## Dataset

The dataset includes the following features:

* Car name
* Year of manufacture
* Present price
* Selling price
* Kilometers driven
* Fuel type
* Transmission type
* Owner type

## Objective

The objective of this project is to build a predictive model that estimates the selling price of a car based on its features.

## Steps Performed

1. Data loading and preprocessing
2. Handling categorical variables
3. Exploratory Data Analysis
4. Feature selection
5. Model training using Linear Regression
6. Model evaluation

## Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Result

The trained regression model can estimate car prices with reasonable accuracy based on the given features.
