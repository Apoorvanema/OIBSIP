# Oasis Infobyte Data Science Internship (OIBSIP)

This repository contains the projects completed as part of the **Oasis Infobyte Data Science Internship Program**.

The objective of these projects is to apply **data science and machine learning techniques** to real-world datasets and gain hands-on experience with data analysis, visualization, and predictive modeling.

## Repository Structure

OIBSIP
│
├── Task1_Iris_Classification
├── Task2_Unemployment_Analysis
└── Task3_Car_Price_Prediction

Each folder contains the dataset, Jupyter notebook, and project documentation for the corresponding task.

---

## Task 1: Iris Flower Classification

This project builds a machine learning model that can classify iris flowers into three different species based on their physical measurements.

Species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

The model learns patterns from sepal and petal measurements and predicts the species of a flower.

---

## Task 2: Unemployment Analysis

This project analyzes unemployment trends during the COVID-19 pandemic.

Using data visualization techniques, the project identifies:

* Trends in unemployment rates
* Regional unemployment patterns
* The impact of COVID-19 on employment levels

---

## Task 3: Car Price Prediction

This project predicts the selling price of cars using machine learning.

The prediction model considers various factors including:

* Present price of the car
* Fuel type
* Transmission type
* Ownership history
* Manufacturing year

A regression model is trained to estimate car prices based on these features.
